# terminal-facts

What terminals really do, for programs that draw pictures in them: one TOML file of
measured and documented facts, with the evidence for each, shared by
[pixcell](https://github.com/visionik/pixcell) (Python) and
[sdl-kitty](https://github.com/visionik/sdl-kitty) (C). A finding, such as "WezTerm's `a=f` never
redraws", is recorded once and reaches both.

- [`terminals.toml`](terminals.toml): the facts.
- [`SPEC.md`](SPEC.md): the format. Facts only (each program keeps its own tuning), how
  terminals are recognised (XTVERSION first), and how version and OS rows stack.
- [`terminal_facts.py`](terminal_facts.py): the reference reader, standard library only
  (Python 3.11+), one file to vendor.

```python
import terminal_facts

found = terminal_facts.identify(terminal_facts.load(), xtversion="ghostty 1.3.1")
found.get("kitty.frame_edit")   # False: Ghostty 1.3.1 doesn't implement a=f
found.get("kitty.shm")          # True
```

A fact that isn't listed is unknown: probe the terminal, or use your own default.

## Adding a finding

1. Set the fact on the terminal's row, or on an extending row for a version or OS, and
   add its evidence: what showed it (eye, probe, source, release notes), the version,
   the date, and which project found it.
2. A new kind of fact goes into the table in `SPEC.md` and into `FACTS` in
   `terminal_facts.py` first.
3. `python terminal_facts.py check`, `python -m pytest`, `python tools/matrix.py`.
